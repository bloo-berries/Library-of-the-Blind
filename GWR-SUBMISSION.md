## Record Criteria

### Measurability
This record is measurable by:
1. **Discrete count** of unique communication methodologies
2. **Verifiable entries** with documented sources
3. **Standardized inventory** (INVENTORY.csv) with unique identifiers

### Breakability
This record can be broken by:
1. Documenting additional verified communication methodologies
2. Discovering and documenting previously unknown historical systems
3. Recognizing newly developed accessibility systems

### Standardizability
The counting methodology is standardized:
1. Each entry requires its own translation tables, teaching materials, or publishing pipeline
2. Sub-variants of parent systems are not counted separately
3. Technology/devices are excluded (only communication methodologies count)
4. Full methodology documented in `taxonomy.md` and `VERIFICATION.md`

### Verifiability
Each entry is verifiable through:
1. Primary reference sources (Perkins World Braille Usage, official standards bodies)
2. Academic and encyclopedia documentation
3. Organization websites and official publications
4. Unique ID in INVENTORY.csv with source links
