## Verification Criteria

### 1. Documentation Requirement
- **Minimum:** At least one verifiable reference source
- **Preferred:** Multiple independent sources

### 2. Distinctiveness Requirement
Each system must require:
- Its own translation tables, OR
- Its own teaching materials, OR
- Its own publishing pipeline, OR
- Distinct community of users

### 3. Status Classification

| Status | Definition | Standard |
|--------|------------|----------|
| **Active** | Currently in use | Post-2000 evidence |
| **Legacy** | Historically significant, superseded | Historical timeline |
| **Historical** | No longer in active use | Historical documentation |
| **Obsolete** | Formally deprecated | Deprecation documentation |

## Quality Assurance

### Entry Addition Protocol
1. **Research:** Identify through authoritative sources
2. **Verification:** Confirm active usage or historical significance
3. **Documentation:** Create entry with verifiable references

### Periodic Review
- Annual review of Active status entries
- Updates based on new research
- Incorporation of newly documented systems
