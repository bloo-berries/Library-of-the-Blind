This document outlines the taxonomy and counting methodology for the Library of the Blind.

## Counting Rules

**Key Principle:** Each distinct system counts as a separate entry because it requires its own translation tables, teaching materials, and publishing pipelines.

## Taxonomy Structure

| Category | Sub-category (example) | Counting Unit |
|----------|----------------------|---------------|
| **Spoken Languages** | English, Mandarin, Swahili | 1 per language with accessibility pipeline |
| **Braille Codes** | UEB, Arabic Braille, Hindi Braille | 1 per distinct Braille code |
| **Alternative Tactile Scripts** | Moon Type, Pro-Tactile, New York Point | 1 per script |
| **Audio Communication Channels** | Screen reader (English), Audio description (French) | 1 per language-channel combination |
| **Tactile/Haptic Modalities** | Refreshable display (English), 3D models (German) | 1 per language-modality pair |
| **Multimodal Systems** | Screen-reader + Braille (English) | 1 per unique pairing |

## Special Categories

### Indigenous / Minority Scripts
- **Count:** 1 per script
- **Examples:** Maori Braille, Inuktitut Braille, Zulu Braille

### Constructed / Niche Languages
- **Count:** 1 per script
- **Examples:** Esperanto Braille, Klingon Braille

## What Counts

### Included (323 total)

**Braille Systems (196)**
- Language-specific codes with distinct character mappings
- Regional variants with significant differences
- Specialized notation (music, math, science)
- Historical systems with documented usage

**Alternative Tactile Scripts (127)**
- Pre-Braille embossed systems
- Dot-based alternatives
- Modern alternative scripts
- Finger-spelling and manual alphabets
- Ancient and historical systems
- DeafBlind methodologies

### Excluded

1. **Sub-variants marked "Part of"** - Share translation tables with parent
2. **Technology/Devices (61 items)** - Implementation tools, not methodologies
3. **Multimodal combinations** - Combine existing systems

## Notes

- Regional variants (e.g., PT-BR vs PT-PT) count separately if significantly different
- Historical systems included for completeness and reference
