Audio-based accessibility technologies and services that provide spoken access to information.

## Screen Readers

Screen readers convert digital text and interface elements into synthesized speech or Braille output.

### Major Screen Reader Software

- **[JAWS](https://en.wikipedia.org/wiki/JAWS_(screen_reader))** - Commercial, Windows, widely used
- **[NVDA](https://en.wikipedia.org/wiki/NonVisual_Desktop_Access)** - Free, open-source, Windows
- **[VoiceOver](https://en.wikipedia.org/wiki/VoiceOver)** - Built-in Apple (macOS, iOS, iPadOS, watchOS, tvOS)
- **[Narrator](https://en.wikipedia.org/wiki/Narrator_(Windows))** - Built-in Windows
- **[Orca](https://orca.gnome.org/)** - Free, open-source, Linux
- **PC-Talker** - Japanese screen reader

### Language Support
- English, Spanish, French, German (all major screen readers)
- Japanese (PC-Talker, NVDA localized)
- Chinese (NVDA localized, various Chinese readers)
- Arabic (JAWS, NVDA with RTL support)
- And many more languages

## Audio Descriptions

Audio descriptions provide spoken narration of visual elements in video content.

### By Language
- **English:** Extensive library in US, UK, Canada, Australia
- **French:** Growing library in France and Canada
- **Spanish:** Available in Spain and Latin America
- **German:** Available in Germany and Austria
- **Japanese:** Available in Japan

## Text-to-Speech (TTS) Systems

Synthetic speech systems that convert text to audio.

### Major TTS Engines
- **[eSpeak](https://en.wikipedia.org/wiki/ESpeak)** - Open-source, many languages
- **[Festival](https://en.wikipedia.org/wiki/Festival_Speech_Synthesis_System)** - Open-source, multiple languages
- **[Google Text-to-Speech](https://en.wikipedia.org/wiki/Speech_Recognition_%26_Synthesis)** - Commercial, many languages
- **[Amazon Polly](https://en.wikipedia.org/wiki/Amazon_Polly)** - Commercial, many languages
- **[Microsoft Speech Platform](https://en.wikipedia.org/wiki/Microsoft_text-to-speech_voices)** - Commercial, many languages
- **Apple VoiceOver TTS** - Built-in, many languages

## Braille Translation Software

- **[Liblouis](https://liblouis.org/)** - Open-source translation library
- **[Duxbury DBT](https://www.duxburysystems.com/)** - Industry-standard translator
- **BrailleBlaster** - BANA-supported translator
- **SWIFT (Braille)** - Spanish translation system

## Accessible Mathematics Software

- **MathJax** - Web math rendering
- **MathML** - XML math markup standard
- **EquatIO** - Google-integrated math
- **MathType** - Equation editor with accessibility
- **ChattyInfty** - Japanese math accessibility

## Accessible Music Software

- **Goodfeel** - Music-to-Braille conversion
- **BME2** - Braille Music Editor
- **FreeDots** - Open-source music Braille
- **Dancing Dots** - Music accessibility company

## Accessible Publishing Formats

- **[DAISY](https://en.wikipedia.org/wiki/DAISY_Digital_Talking_Book)** - Digital Accessible Information System
- **EPUB 3 Accessibility** - eBook accessibility standard
- **PDF/UA** - Accessible PDF standard
- **Bookshare** - Accessible book library
- **BARD (NLS)** - National Library Service system

## Notes

- Screen reader localization is crucial for accessibility
- Audio descriptions make visual media accessible
- TTS quality varies significantly by language and engine
