Specialized Braille codes designed for specific domains beyond literary text.

## Music Braille

### [Braille Music Notation](https://en.wikipedia.org/wiki/Braille_music)
- **Inventor/Developer:** Louis Braille
- **Date:** 1829-present
- **Description:** Louis Braille's original music notation system. Uses the same six-position braille cell as literary braille, but assigns its own meanings and has its own syntax.
- **Status:** Active standard
- **Key Features:**
  - Uses six-dot cells with independent syntax from literary Braille
  - Notes aligned with solfege system
  - Rhythm indicated by dots 3 and 6
  - Octave marks specify octave ranges
  - Represents notes, rhythms, dynamics, accidentals, tempo markings

### [New York Point Music](https://www.merriam-webster.com/dictionary/New%20York%20point)
- **Inventor/Developer:** William Bell Wait
- **Date:** 1868-1916 (obsolete)
- **Description:** Musical notation system based on New York Point, where notes are made by combining two 'primitives' (digits 1-7).
- **Status:** Obsolete

### [Carnatic Music Braille](https://www.thehindu.com/features/metroplus/society/on-a-fresh-note/article5673410.ece)
- **Origin / Users:** India
- **Description:** Specialized Braille code for Carnatic (South Indian classical) music notation.
- **Status:** Active

## Mathematics Braille

### [Braille Mathematics (Nemeth Code)](https://en.wikipedia.org/wiki/Nemeth_Braille)
- **Inventor/Developer:** Abraham Nemeth
- **Date:** 1952-present
- **Description:** Comprehensive Braille code for mathematical and scientific notation.
- **Status:** Active (primarily in US)
- **Key Features:**
  - Supports algebra, calculus, geometry, trigonometry, statistics
  - Handles fractions, radicals, superscripts, subscripts
  - Widely used in educational settings in the United States

### [Marburg Mathematical Notation](https://chezdom.net/mathematicalbraillecodes/)
- **Origin / Users:** Germany/Europe
- **Description:** European standard for mathematical and scientific Braille notation.
- **Status:** Active (primarily in Europe)

### [Unified English Braille (UEB) Technical](https://en.wikipedia.org/wiki/Unified_English_Braille)
- **Date:** 2010s-present
- **Description:** Technical and mathematical notation system integrated within the UEB framework.
- **Status:** Active

### [Advanced Braille Code for Mathematics and Science (India)](https://niepvd.nic.in/braille-development/)
- **Origin / Users:** India
- **Description:** Advanced Braille code developed by NIEPVD for mathematics and science.
- **Status:** Active

## Computer Braille

### Computer Braille Code (CBC)
- **Description:** Designed for representing computer syntax (brackets, punctuation) in Braille
- **Status:** Active
- **Key Features:**
  - Specialized cells for programming symbols
  - Used in coding and technical documentation

### 8-Dot Braille (Computer Braille)
- **Date:** 1970s-present
- **Description:** Extended cell with two additional dots for encoding 256 characters
- **Status:** Active
- **Key Features:**
  - Extended 8-dot cell (vs. standard 6-dot)
  - Can encode 256 characters
  - Used in computing and technical applications

## Braille Grade Systems

### Grade 1 Braille (Uncontracted)
- **Description:** Letter-by-letter transcription
- **Status:** Active
- **Key Features:**
  - Basic Braille system
  - Each letter transcribed individually
  - Used for learning and simple texts

### Grade 2 Braille (Contracted)
- **Description:** Uses 180 different letter contractions including 75 shortform words
- **Status:** Active (most common)
- **Key Features:**
  - Reduces paper volume significantly
  - Standard for most Braille publications

### Grade 3 Braille / Personal Shorthand
- **Description:** Advanced, highly abbreviated extension beyond Grade 2
- **Status:** Obsolete (personal use only)

## Accessibility Adaptations

### [Jumbo Braille](https://www.languagehumanities.org/what-is-jumbo-braille.htm)
- **Description:** Enlarged Braille cells for users with reduced tactile sensitivity
- **Status:** Active
- **Key Features:**
  - Larger cell size (typically 1.5x to 2x standard)
  - Essential for elderly readers and those with diabetic neuropathy
